# Agent Note: 默认社区用量统计

Status: implemented

[English](2026-08-26-default-community-usage-analytics.md) | 中文

## Problem

Web 与桌面表层需要低门槛展示供应商余额、订阅配额、token 总量、缓存效果与每日活动。要求用户先通过插件市场安装，会使首次启动缺少基本本地用量信息；用户还必须多完成一步设置，才能判断账户状态或缓存行为。

用量统计会接触凭据、持久会话日志、向供应商发出的请求、回环 HTTP 路由与持久本地摘要。如果没有固定源码和安全审查就把任意社区版本加入默认 profile，会在不透明的情况下扩大默认信任集合。

## Decision

[`@deepseek-ai/dsh-web-app`](../../../../packages/bundle/web-app/README.zh.md) 以准确版本 `0.2.9` 依赖 `@ychris12138/dsh-usage-stats`，并通过普通的 `usage-stats` Cordis 配置项挂载。因此，浏览器、桌面直接运行壳与已安装桌面应用共用同一个 Host/Client 双面插件。profile overlay 可以停用或替换该配置项，而无需修改 Electron 或 Web 宿主。

该插件贡献侧边栏中的**用量/余额**操作与面板。它根据本地聚合的会话用量，展示所选供应商的余额或订阅窗口、今日／本月／累计 token 总量、缓存命中率与每日热力图。Host 解析已配置的供应商凭据，只返回规范化账户值，并把折叠进度持久化到 `DSH_HOME/storages/usage-stats-cache.json`；缓存不包含提示词、回复、工具数据、凭据或文件路径。

该依赖保持为外部包，不复制已编译 JavaScript。已审查的 npm 产物标识 Git 提交 [`f91cf9843425616e0730a459c25d4f340e448e47`](https://github.com/Ychris12138/dsh-usage-stats/tree/f91cf9843425616e0730a459c25d4f340e448e47)，`pnpm-lock.yaml` 固定其 registry 完整性。该包保留上游 MIT 版权与许可证，仓库生成的第三方声明会披露此依赖。更新准确版本时，必须重新审查源码、许可证、行为与测试。

## 安全与生命周期

已审查版本不声明生产依赖或安装生命周期脚本。账户路由只接受回环调用方与只读方法；供应商凭据保留在 Host。内置适配器只访问对应供应商端点；声明式监测器默认使用 HTTPS、同源相对路径、手动重定向、有界 JSON 响应、DNS 校验与地址固定，并拒绝私有网络。

Host 会立即执行一次聚合／账户刷新，之后每 5 分钟重复。没有配置凭据的账户只在本地保持 `not-configured` 状态；已配置账户可能在面板打开前联系对应供应商。dispose（资源释放）会清除定时器并等待正在运行的刷新完成。该插件既不注册模型输入，也不修改会话事件。

## Alternatives considered

**把发布的 JavaScript 复制进 monorepo。** 否决，因为发布包是已编译的手工 bundle，不符合本仓库的 TypeScript 包和 Client CSS 约定。复制会形成不透明 fork，并失去上游发布标识、安全修复与测试套件。

**重写一个较小的第一方统计包。** 本次集成否决，因为复刻供应商规范化、订阅窗口、DNS 地址固定、重启安全折叠与浏览器展示，会重复一个持续维护的实现。如果外部包的 API 或维护状态不再满足本 profile 要求，仍可改用第一方实现。

**只把统计功能作为插件市场可选安装项。** 否决，因为余额与缓存效果是本发行版的基础运行反馈。实现仍是一个可移除的 Cordis 配置项，因此既能默认展示，也保留插件组合方式。

**跟随 Git 分支或版本范围。** 否决，因为默认依赖的可执行代码不能绕过已审查的 manifest 与锁文件变更而发生变化。

## Testing

固定的上游版本通过 bundle、Client 渲染、overlay 顺序、Host 路由、余额适配器、订阅适配器、账户安全、缓存与安装器程序。组装后的本地 Web profile 会在无凭据时返回成功的空用量与供应商响应、创建聚合缓存、渲染“用量/余额”面板与缓存命中率字段，并保留与其共存的内置插件市场。桌面运行时闭包与安装包检查通过 Web 组合包覆盖该依赖。

## Consequences

每次默认 Web 或桌面启动都提供本地用量与账户信息，自包含安装包也会带上已审查的准确版本。用户无需额外安装插件，也不需要另一套桌面 API。

默认 profile 会增加一个外部可执行依赖、一个本地聚合缓存和周期性 Host 工作。已配置账户可能在后台请求供应商，上游行为也不会自动接受本 monorepo 的静态检查。维护者必须明确审查每次版本更新；如果对应信任或维护成本不再可接受，则应停用该配置项。
