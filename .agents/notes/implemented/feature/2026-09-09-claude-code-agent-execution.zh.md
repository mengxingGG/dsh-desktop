# Agent Note: 主智能体与 Crew 智能体的 Claude Code 执行

Status: implemented

[English](2026-09-09-claude-code-agent-execution.md) | 中文

## 问题

用户需要为主 Agent 和稳定的 Crew 成员分别选择执行器与模型，并使用 Claude 原生登录、账号额度、实时工具活动和可恢复对话。[一次性产品提供方](../../implemented/feature/2026-08-04-claude-code-and-codex-subagent-backends.zh.md)有意只返回独立任务的结果，无法提供这种交互。

## 决策

在 Agent 注册表中以独立的模型提供方路由注册外部执行器。Agent 循环保留准入、冻结请求重建、作用域工具、权限、临时 assistant 流和持久化 Session 输出；执行器负责一个步骤内的原生模型迭代和进程清理。主模型选择与 [Crew 角色偏好](../../implemented/feature/2026-09-05-crew-role-policies-and-global-memory.zh.md)使用同一目录，并保留稳定的 DSH 成员 Session。

Claude 执行器使用固定版本的官方 Agent SDK 和 CLI。其原生工具、技能及项目设置被禁用；进程内 MCP 服务器只暴露 DSH Agent 组装后的工具 schema，并将已提交的调用标识交给 DSH 权限检查。原生对话绑定和完整历史检查点决定是否可以恢复。分叉、被中断的原生输入以及发生分歧的历史都会从已记录的 DSH 历史初始化新的原生对话。

原生认证负责凭证。设置插件展示有长度限制的登录输出，并转交用户明确输入的内容。额度刷新调用固定版本 CLI 的结构化用量控制接口，不发起推理；额度事件保留各自的观测时间。缺失额度保持未知。加载插件不会发起模型请求，也不要求或创建 Git 仓库。

输入框使用独立的 `claudeUsage` 投影，展示原生逐请求观测。重复的 assistant 块不会重复累计用量；模型结果的容量决定分母，原生压缩会清除旧占用。额度为账号共享数据，独立刷新且不发起推理。Windows 本地启动器调用现有桌面开发路径，保留其数据目录；启动依赖工作目录及构建产物。

## 考虑过的替代方案

LLM 适配器无法表达自行迭代工具的 CLI。纯终端文本抓取会丢失调用标识和审批归属。启用 Claude 原生工具会让 Crew 管理者绕过 DSH 角色限制。一次性提供方保留为独立入口；其只返回结果的语义仍然有用，并未被取代。Crew 角色和产品提供方记录保持有效，因为本提案只扩展其执行选择。

## 验证

- 模型目录和委派测试覆盖主智能体、普通子智能体及 Crew 路由选择，包括在推理前拒绝无效选择。
- 官方 SDK 与原生 CLI 测试覆盖实时输出、DSH 工具审批、取消、分叉，以及持久化历史下完整 Host 重启后的恢复。
- 账号测试覆盖登录生命周期、额度单位、不可用数据和进程清理。订阅探针使用 Sonnet 5；账号和额度控制不发送推理提示。
- Claude SDK 的规范 Session 提供 TypeScript 和 Python 的结果、通知及持久化投影。将 `DSH_PYTHON` 设为已安装 Python SDK 依赖的 Python 解释器，即可启用 `snapshots/sdk/sdk.snapshot.ts` 中的 Python 投影。
- 浏览器与原生 Windows Electron 测试覆盖账号设置、图片输入、稳定 Crew 续接及发布配置组合。包卫生检查验证可安装的运行时文件。

后续补充的输入框用量显示与本地 EXE 交由用户测试。此次交付仅包含编译；上述既有检查不代表这部分补充已经通过运行时验收。

## 后果

原生用量控制接口仍为实验性，并固定了版本。Claude 对话存储归 CLI 所有，原生恢复依赖该存储可用。SDK 协议变化需要更新测试并进行原生验证；格式错误的观测会明确报错，而不会编造额度或把部分结果报告为成功。

配置依赖遍历先将符号链接清单解析到其安装目录，再发现嵌套依赖。快照补丁先解析自身依赖，再解析快照库的回放依赖，使测试插件不进入生产配置。Linux 录制的 shell 快照仍由 Linux 验证；Windows 浏览器与原生进程测试负责本次接入的本机运行时验证。
