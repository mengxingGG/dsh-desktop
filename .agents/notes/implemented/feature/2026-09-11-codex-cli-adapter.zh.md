# Agent Note: Codex CLI 执行与 DSH 工具职责

Status: implemented

[English](2026-09-11-codex-cli-adapter.md) | 中文

## 问题

主智能体与持久 Crew 成员需要使用用户的原生 Codex 订阅、可选模型和额度显示。把整个项目交给原生编码代理会绕过 DSH 工具准入，并将执行记录分散到彼此无关的编排系统。

## 决策

[共享 CLI 执行器](../../../../packages/subagent/agent-cli/README.zh.md)在 [Grok 与 Antigravity 路由](2026-09-11-grok-antigravity-cli-adapters.zh.md)旁注册 `codex-cli`。原生 app-server 管理认证、模型发现和持久线程。每轮返回现有的 DSH 结构化响应；DSH 验证、记录并执行请求的工具。续接要求相同的 DSH 所有者、模型、推理强度、指令、工具及已同步消息前缀。中断或分歧输入从 DSH 历史重新启动。

适配器要求原生只读、禁网沙箱，拒绝审批请求，禁用原生执行功能、继承的 MCP 条目和钩子，并使用私有协议目录。除消息、推理和上下文压缩之外的原生条目均被拒绝。这些限制不会让只读沙箱变成文件读取白名单；模型负载下的实际隔离与取消需要运行验收。路由不包含原生 Git 初始化、worktree、安装器或账号重置。

账号及分页模型查询不需要推理。手动原生额度查询保留独立额度池、不可用窗口与重置时间，不消耗重置额度。原生累计令牌差值描述本次调用，最新请求计数及实际上下文容量描述上下文占用。未知值保持未知，包括单次订阅调用成本。

## 考虑过的替代方案

**原生项目工具：** 原生执行可以省去 JSON 响应格式，但会绕过 DSH Crew 工具作用域及已记录的结果路径。适配器保留 DSH 的执行职责。

**原生动态回调：** app-server 支持动态工具，但第二套回调生命周期会重复现有工具准入路径。结构化响应与其他 CLI 适配器共用分派及续接语义，代价是缓冲最终正文。

**直接调用订阅 API：** 原生 app-server 保留原生凭据处理和模型可用性。读取凭据文件或模仿订阅请求会引入另一套认证实现。

## 影响

Codex 通过相同的主智能体与 Crew 模型选择入口使用，包含原生推理强度。支持文本和 DSH 工具结果；图片、温度、停止序列及输出令牌上限覆盖会被拒绝。原生工具进度不属于 DSH 执行流。独立的一次性 `subagent-codex` 提供方保留自己的执行策略。

原生 CLI 0.153.4 提供了生成的协议 schema。本机只读检查确认已有 ChatGPT 账号、六个可用模型及推理强度、多个额度池和只读配置。沙箱内检查无法访问账号，相同的本机检查成功。未发起模型轮次、重置登录或检查凭据文件。自动化用例覆盖计量准入但尚未运行；模型执行、原生工具隔离、取消及 Session 录制回放仍由用户验收。

Claude 执行及 Grok/Antigravity 记录保持有效，其回调职责和原生权限决策仍独立适用；本记录补充 Codex 专属协议与计量决策。
